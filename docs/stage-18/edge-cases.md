## Не проверено
- Очень длинные русские названия: полей для них нет, поэтому проверка не нужна, пока не появятся пользовательские названия.
- Вставка текста с невидимыми символами (неразрывный пробел) в поле: `trim()` убирает его по краям, внутри строки он отклоняется.
