## Подготовка

- Файлы скачаны через API Poly Haven (`https://api.polyhaven.com/files/<id>`, вариант glTF 1k) в `public/models/<id>/` без изменений.
- Единица файлов — метр. Пересчёт в сцену выполняется один раз (`modelScaleToScene`).
- Габариты измерены командой `node scripts/measure-model.mjs public/models/<id>/<id>.gltf` и округлены до сантиметра.
- Опора: при загрузке центр основания модели переносится в начало координат (`src/scene3d/FurnitureModel.tsx`); исходные файлы не меняются.
- Оптимизация (сжатие геометрии и текстур) не выполнялась — задача 13.3.

## Замечания

- Sofa 03 — диван классического стиля, а желаемая стилистика каталога современная (FR-12). Для технической проверки подходит, в рабочий каталог не рекомендуется.
- Модели FurniMesh в проекте пока не используются. Вопрос их лицензии открыт (SPEC §12).
