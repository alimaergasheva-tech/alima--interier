# Планировщик интерьера

Браузерный планировщик квартиры для ремонта: геометрия, мебель, отделка, синхронные 2D-план и 3D.
Требования — [PRD](PRD-interior-planner.md), технические правила — [SPEC](SPEC.md), план и журнал — [Tasks.md](Tasks.md).

Состояние: готова техническая сцена (этап 4) — одна комната с тремя моделями, синхронные план и 3D, перенос и поворот с запретом выхода за стену. Стартового сценария, проёмов, отделки и рабочего каталога пока нет. Источники моделей — [ASSETS.md](ASSETS.md), отчёт этапа — [docs/stage-4/REPORT.md](docs/stage-4/REPORT.md).

## Требования

- Node.js 22.12 или новее (проверено на 26.13.0), npm (проверено на 11.20.0).
- Установленные Chrome и Edge — для браузерных проверок; Playwright использует системные браузеры и ничего не скачивает.

## Команды

Выполняются в папке `interior-planner`. Из родительской папки `19-30` добавляйте `--prefix`, например `npm --prefix interior-planner run dev`.

| Команда | Назначение |
|---|---|
| `npm ci` | Установка зависимостей строго по `package-lock.json` |
| `npm run dev` | Локальный запуск: http://localhost:5173 |
| `npm run typecheck` | Проверка типов |
| `npm test` | Модульные тесты (Vitest, `tests/unit`) |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run e2e` | Браузерные проверки (Playwright, `tests/e2e`) в Chrome и Edge; dev-сервер запускается сам |

## Стек

React 19, TypeScript 7, Vite 8, Three.js 0.187, React Three Fiber 9, Drei 10, Zustand 5, Vitest 5, Playwright 1.65.
Точные версии зафиксированы в `package-lock.json`.

## Структура

- `src/domain` — модель квартиры в сантиметрах, единицы, площади, проверка целостности.
- `src/commands` — предложение и атомарное применение изменений, история отмены, горячие клавиши.
- `src/store` — данные проекта (`projectStore`) отдельно от состояния интерфейса (`uiStore`).
- `src/geometry` — валидатор размещения, общий для плана и 3D.
- `src/interaction` — цикл переноса и реестр областей (план, 3D).
- `src/plan2d`, `src/scene3d` — два представления одной модели.
- `src/catalog`, `src/tech` — технический каталог и техническая комната этапа 4.
- `src/ui/theme.css` — переменные тёмной темы (SPEC D-13).
- `scripts/measure-model.mjs` — габариты glTF-модели; `scripts/capture-stage4.mjs` — кадры и замеры.
- `tests/unit` — модульные тесты; `tests/e2e` — браузерные сценарии.
