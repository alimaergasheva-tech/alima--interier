# Планировщик интерьера

Браузерный планировщик квартиры для ремонта: геометрия, мебель, отделка, синхронные 2D-план и 3D.
Требования — [PRD](PRD-interior-planner.md), технические правила — [SPEC](SPEC.md), план и журнал — [Tasks.md](Tasks.md).

Состояние (20.11.2026, релиз 1.0 завершён): готов основной сценарий — выбор числа комнат и площади, три схемы, настройка стен, окон и дверей, интерьер с каталогом мебели и техники, отделка (краска, обои, полы), тёмный интерфейс, время суток с небом и внешним миром, свет в комнатах и светильники, прогулка по всей квартире, отмена и повтор, «Качественный снимок». Приёмка по критериям — [docs/stage-19/acceptance.md](docs/stage-19/acceptance.md). Источники моделей — [ASSETS.md](ASSETS.md).

## Известные ограничения

- «Качественный снимок» (path tracing в браузере, D-09) работает на Mac M1: около 1,2 с на выборку (64 выборки — 76 с, 256 — 307 с); принят пользователем 20.11.2026, экспорта файла нет, в Edge и на эталонном ПК не проверялся.
- Совместимость и скорость проверены в Chrome на Mac (Apple M1); Edge и эталонный ПК (GTX 1660 SUPER) не проверялись.
- Оптимизация моделей и составные коллайдеры сделаны только для части предметов (задачи 13.2–13.4).
- Лицензия моделей FurniMesh не подтверждена, они в проекте не используются (SPEC §12).
- Публикации и деплоя нет: приложение запускается локально.

## Требования

- Node.js 22.12 или новее (проверено на 26.13.0), npm (проверено на 11.20.0).
- Установленные Chrome и Edge — для браузерных проверок; Playwright использует системные браузеры и ничего не скачивает.

## Команды

Выполняются в папке проекта (`alima`). Из другой папки добавляйте `--prefix`, например `npm --prefix alima run dev`.

| Команда | Назначение |
|---|---|
| `npm ci` | Установка зависимостей строго по `package-lock.json` |
| `npm run dev` | Локальный запуск: http://localhost:5173 |
| `npm run typecheck` | Проверка типов |
| `npm test` | Модульные тесты (Vitest, `tests/unit`) |
| `npm run build` | Проверка типов и сборка в `dist/` |
| `npm run e2e` | Браузерные проверки (Playwright, `tests/e2e`) в Chrome и Edge; `-- --project=chrome` — только Chrome; dev-сервер запускается сам |
| `npm run previews` | Превью предметов каталога (после добавления моделей) |

## Стек

React 19, TypeScript 7, Vite 8, Three.js 0.187, React Three Fiber 9, Drei 10, Zustand 5, Vitest 5, Playwright 1.65.
Точные версии зафиксированы в `package-lock.json`.

## Структура

- `src/domain` — модель квартиры в сантиметрах, единицы, площади, проверка целостности.
- `src/commands` — предложение и атомарное применение изменений, история отмены, горячие клавиши.
- `src/store` — данные проекта (`projectStore`) отдельно от состояния интерфейса (`uiStore`).
- `src/geometry` — валидатор размещения, общий для плана и 3D.
- `src/interaction` — цикл переноса и реестр областей (план, 3D).
- `src/plan2d`, `src/scene3d` — два представления одной модели.
- `src/catalog`, `src/tech` — каталог мебели и отделки (краска, обои, полы), техническая комната этапа 4.
- `src/layouts` — 10 стартовых схем планировок (площади — SPEC §3.1, сверяются тестом `tests/unit/stage22.test.ts`).
- `src/walk` — прогулка по квартире: столкновения, свет в движении; `src/scene3d` — также небо и внешний мир, время суток, свет в комнатах.
- `src/ui/theme.css` — переменные тёмной темы (SPEC D-13).
- `scripts/measure-model.mjs` — габариты glTF-модели; `scripts/capture-stage4.mjs` — кадры и замеры.
- `tests/unit` — модульные тесты; `tests/e2e` — браузерные сценарии.
